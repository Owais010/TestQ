# AI QA Agent — Demo Application

A deliberately vulnerable and buggy web application created for demonstrating the capabilities of an **AI-powered independent QA testing platform**.

> This project intentionally contains bugs, validation issues, and unexpected behaviors.
> It is designed for testing purposes only.

## Purpose

This repository acts as a demo target for the AI QA Agent.

The QA platform accepts this GitHub repository, builds and runs the application, performs automated UI and API testing, and identifies the intentionally introduced issues.

## Tech Stack

- Next.js
- TypeScript
- React
- Node.js
- SQLite

## Features

- User registration
- User login
- Dashboard
- Product listing
- Product search
- Shopping cart
- Admin panel
- REST API
